# Автотесты UI для сервиса Stellar Burgers

Данный репозиторий содержит пакет автоматизированных тестов для пользовательского интерфейса (UI) космической бургерной **Stellar Burgers**. Тесты написаны на языке **Python** с использованием фреймворка **Pytest** и библиотеки **Selenium**. Для генерации наглядных отчетов интегрирован **Allure**.

## 🛠 Технологический стек

- **Язык программирования:** Python 3.10
- **Тестовый фреймворк:** Pytest
- **Инструмент автоматизации UI:** Selenium WebDriver (включая webdriver-manager)
- **Отчетность:** Allure Framework

## 📂 Структура проекта

Архитектура проекта:

- pages/ — реализация паттерна Page Object Model (POM); изолированный слой страниц приложения (base_page.py и др.), содержащий локаторы элементов и логику взаимодействия с интерфейсом без тестовых проверок.
- tests/ — тестовые сценарии, сфокусированные на проверках поведения и интерфейса веб-приложения.
- tests/conftest.py — конфигурационный файл Pytest с фикстурами для генерации предусловий (инициализация и закрытие драйвера браузера, авторизация).
- helpers/ — утилиты для генерации случайных уникальных данных пользователей и вспомогательные инструменты.
- data.py — хранение тестовых данных (тексты элементов, URL-адреса страниц, ожидаемые сообщения).
- requirements.txt — зафиксированные версии внешних библиотек.
- allure-report/ — финальный статичный HTML-отчет для ревьюера.

## 🚀 Инструкция по локальному запуску

### 1. Подготовка окружения

Клонируйте репозиторий и установите все необходимые зависимости в ваше виртуальное окружение ( venv ):

```bash
pip install -r requirements.txt
```

### 2. Запуск автотестов

Для прогона всех тестов и генерации сырых результатов Allure выполните:

```bash
pytest --alluredir=allure-results
```

### 3. Работа с Allure-отчетами

- Для сборки и **автоматического открытия** интерактивного отчета в браузере: `allure serve allure-results`
- Для локального просмотра уже сгенерированного отчета, загруженного в репозиторий: `allure open allure-report`
